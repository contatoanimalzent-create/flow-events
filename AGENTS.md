# Fluxo obrigatorio de entrega

- Toda alteracao comeca por uma Issue.
- Desenvolver em branch dedicada; nunca fazer mudanca diretamente em `main`.
- Todo deploy entra por Pull Request, cuja descricao referencia `Closes #<issue>`.
- Validar tipos, testes e funcoes afetadas antes de solicitar merge.
- Credenciais e chaves de integracao nunca podem chegar ao cliente ou aos logs.
